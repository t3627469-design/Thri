

1.4.1 (TheOne patch: placement brain, instinct speed, build up)
- Right orientation, first time: before every click it runs Minecraft's own placement logic for that exact click
  (face, hit point and the rotation the server will see) and only clicks when the result matches the schematic:
  facing, axis, stair/slab/trapdoor half, button/lever face, sign/banner/skull rotation, door hinge, wall vs floor
  torches/signs/banners/heads. It picks a face and spot that work; if a block can't be oriented right from anywhere
  for ~10 seconds it is placed anyway so the build never stalls.
- speed 6 = instinct: no delay, instant aim, one block per tick. only-build defaults to 6.
- Build up, both only-build and human-builder, creative and survival, no flying (flight is switched off when the
  builder has to move): when the spot to stand on is 2+ blocks up, it builds a pillar of spare blocks (cobblestone, dirt, ...) beside
  the build (cobblestone in creative), climbs it, steps onto the finished layers and keeps building from there. The pillar is mined down when
  the build is done, or human-builder leaves to shop/fetch. It no longer comes down just because nothing was reachable for a minute; it keeps the pillar and posts a warning instead.
- Any error in the new code switches the new code off after 3 hits and the original behaviour takes over.

1.6.2 (floating blocks are reported)
- When every block left to build floats (no placed block beside it to click), only-build and the printer now say so
  in chat: how many blocks float and what to do. Before, they quietly ended with "Done: N placed, M skipped".
- Only-build places a block only against a block that is already there. The bundled Sweet Berries farm is mostly
  floating: most of its blocks sit in pieces with nothing in the schematic beside them, so only the part that touches
  the ground can be built, and the rest is reported. Building floating parts needs temporary support blocks, which
  this version does not place.

1.6.1 (printer walks when nothing is in reach)
- Printer module (TheOne > printer) now moves. Each build tick it places the nearest block in reach that can be
  placed facing right: it turns to look at it and clicks. When nothing in reach can be placed, the bot walks to the
  next block, the same as only-build. 1.6.0 never walked, so it stopped after the first reachable blocks.
- Printing places only blocks in the layer being built (lowest layer still pending), so it can't wall itself in
  with the floor it is standing on. Tested in the offline simulator: 82-92 of 93 placed across seven seeds, none wrong.
- Placement and standing rules are the same as only-build (1.5.0): nothing is placed the wrong way.

1.6.0 (printer)
- Printer module (TheOne > printer): place the only-build schematic from where you stand. Every tick it finds the
  nearest block in reach that can be placed facing right, turns to look at it, and places it. It never walks or
  climbs; you do the moving. Turn it on, pick the schematic and speed in only-build's settings, and it runs.
- Shipped the stand-spot search (Stand.find) for real: the 1.5.0 packager left Stand.class out of the jar.

1.5.0 (only-build rebuilt around the real placement rules; tested in an offline simulator)
- Never places a block the wrong way: a block is placed only when the click will produce the schematic state
  (stairs facing and half, logs, slabs, buttons, ...). Removed the old "place it wrong after a timeout" fallback.
- Stands where it can place: a standing spot is only chosen if a correctly oriented face is visible from every
  point of that cell, so the builder stops next to a block that it can't actually click.
- Turns first, clicks next tick: the click uses the crosshair from before the turn, so a same-tick turn gave the
  wrong facing. Mining follows the same rule.
- Walks by hand correctly: the manual walker only moved when a block was in front of it; it now walks forward on
  open ground and steps up one-block ledges.
- Blocks it can't place facing right from anywhere reachable are skipped and named in a warning, not placed wrong.
  If nothing is placed for about 75 seconds, what's left is dropped and named the same way.
- Pillars come down when the build is finished (or human-builder leaves to shop), not because a block was out of
  reach for a minute.
